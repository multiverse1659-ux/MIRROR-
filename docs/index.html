One-time setup (about 5 minutes, no Xcode/Android Studio needed)

  1. Create a free GitHub account if you don't have one, then create a new repository.
  2. Upload everything from this project (drag the folders into GitHub's web uploader, or use git push) — including the .github/workflows/build.yml file, which does the building for you.
  3. On your repo's page, go to Releases → Draft a new release, type a tag like v1.0, and click Publish release. This triggers the automated build — check the Actions tab to watch it run (~5–10 minutes, mostly the Mac build).
  4. Once it finishes, refresh your release page — MirrorSender.apk and MacMirror.dmg will be attached to it automatically.
  5. Open this page's HTML file, find the two lines near the top of the <script> that say GITHUB_OWNER and GITHUB_REPO, and fill in your GitHub username and repo name. That's the only edit needed — the download buttons will then always point at your latest release.
Both devices need to be on the same Wi-Fi network to connect.
